# datafun-06-eda

Module 6 assignment for NWMSU Data Analytics Fundamentals

## Dataset used for this project: healthexp.csv

[Link to healthexp.csv source](https://github.com/mwaskom/seaborn-data/blob/master/healthexp.csv)

Number of records: 274

### Description of columns in healthexp.csv data

* Year: the year the health data was taken  
* Country: the country for which the data was taken  
* Spending_USD: healthcare expenditure (total spending on healthcare) per capita, in United States dollars  
* Life_Expectancy: average life expectancy for a citizen of the country listed, in years
